# 玩家连接审计

`AuditService.ReportPlayerConnectionEvent` 是带游戏服凭据认证的一元 RPC。进服与离服包括未注册、未登录玩家，与中心账户登录成功是不同事件。

游戏服在每次进服生成非零 UUID，并在本次离服时使用同一个 ID。请求中的名字来自实际玩家对象。中心从认证上下文取得服务器 ID，自行生成审计记录 ID、接收时间；不要求账户存在，也不保存中心在线会话。

事件时间只要求合法 Timestamp，不强制与中心时钟接近。记录按尽力投递处理，不保证顺序、唯一性或完整性；连接 ID 不是幂等键。RPC 成功表示数据库写入成功，超时结果不确定，调用方仍不得自动重试。离服、断线、停服和进程崩溃可能造成记录缺失，不补报、不推导虚假离服。

非法参数返回 InvalidArgument；服务器凭据失效返回 Unauthenticated；写入失败返回 Internal；取消与截止时间保留对应 gRPC 状态。审计失败只记录安全的调用结果，不改变注册登录、门禁和正常游戏行为。

不采集密码、服务器密钥、JWT、完整命令、IP 或坐标，也不提供任意附加字段。首期不新增审计查询 HTTP API。
