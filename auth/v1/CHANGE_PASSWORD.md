# 玩家自助改密 RPC v1

本次改密协议待审查，尚未实现业务或更新消费者引用。定义见 [auth.proto](auth.proto)，沿用 [玩家认证契约](README.md) 的服务器凭据、名字和密码规则。

## 方法与请求

Unary RPC：`/realmmesh.auth.v1.AuthService/ChangePassword`。

`ChangePasswordRequest` 包含 `player_name`、`old_password`、`new_password`。游戏服仅允许当前已登录连接发起，从真实连接取得名字；确认新密码由命令入口比较，不上传第二份新密码。中心不维护玩家会话，依靠可信游戏服限制入口，并独立验证旧密码，不把服务器凭据当作玩家密码证明。

每次调用通过既有 metadata 校验服务器凭据。消息不携带服务器 ID、JWT、管理员标志或操作目标列表。密码、完整请求及含密码的命令不得写入日志，密码不得持久保存在游戏服。当前明文通道不提供传输加密。

## 校验与共享失败状态

1. 服务器认证通过后校验名字；非法名字返回 `InvalidArgument`，不计数
2. 查找未删除账户；不存在或已删除返回 `UNREGISTERED`，不计数，要求发起连接清除认证并退出
3. 先判断休息期；尚未到期直接返回 `COOLING_DOWN`，不校验新旧密码，不延长截止时间，每次均要求踢出
4. 非休息账户先检查新密码格式；不符合注册规则返回 `InvalidArgument`，不校验旧密码、不增加或清零失败次数
5. 校验旧密码；错误（包括格式错误）与登录共享持久化计数，第 N 次失败立即进入中心配置规定的休息期，到期后的下一次有效密码尝试从零计数
6. 旧密码正确后保存新密码哈希并清零失败次数与休息状态；仅在提交成功后返回 `SUCCEEDED` 并广播密码变更通知

默认阈值 3、休息 300 秒，实时策略来自中心系统配置，不另建改密配置。同一账户跨游戏服、名字大小写以及登录与改密调用共用状态。例如登录错两次，再改密时旧密码错一次，立即进入休息期。成功登录或成功改密均清零；仅旧密码正确但更新失败不算改密成功，不清零。

并发登录、改密和删除须以中心实际持久化顺序维护一致性。已经失效的旧密码不能覆盖后来提交的新密码；失败操作不广播，数据库或哈希处理故障不计作旧密码错误。

## 响应约束

下表省略 `CHANGE_PASSWORD_STATUS_` 前缀。响应不重复返回身份或令牌，不用于将玩家标记为已登录。

| status | remaining_attempts | cooldown_until | retry_after_seconds | kick |
| --- | --- | --- | --- | --- |
| SUCCEEDED | 清零后的中心失败阈值 | 不设置 | 0 | true |
| UNREGISTERED | 0 | 不设置 | 0 | true |
| WRONG_PASSWORD | 大于 0 | 不设置 | 0 | false |
| COOLING_DOWN | 0 | 原截止时刻 | 大于 0 | true |

截止时刻使用 `google.protobuf.Timestamp`，其余状态不设置该字段。剩余秒数由中心在判断时向上取整，仅用于提示，不授权游戏服按本地时钟提前结束休息。中心不发送零值；客户端收到未知枚举或不符合字段约束的响应时不能视作成功。

密码错误、账户不存在和休息期均返回 gRPC OK 与上述业务结果。服务器认证失败为 `Unauthenticated`；依赖暂时不可用为 `Unavailable`；内部错误、配置异常或已存哈希损坏为 `Internal`；取消和超时为 `Canceled` / `DeadlineExceeded`。错误信息只返回安全摘要。

## 踢出、通知与重试

- 成功响应要求发起连接清除认证并退出，提示“账户密码已变更，请重新进入并登录”；账户不存在提示“账户不存在或已删除，请重新进入”；休息期按剩余秒数提示并踢出
- 提交成功后沿用 [账户变更通知](ACCOUNT_EVENTS.md) 广播 `PASSWORD_CHANGED`。通知与响应无先后保证，任一先到都可触发断开，后到结果不得恢复认证或作用于重新进入的新连接
- 通知取消在途请求可能导致发起方未收到成功响应；这不表示改密回滚。发送通知失败也不回滚已提交改密，不补发，不撤销既有 HTTP JWT
- 不自动重试改密：超时、取消或断线时操作可能已经提交，重放可能以失效旧密码增加共享失败次数

本 RPC 不支持管理员重置或删除账户。首期删除通过必要的管理员 HTTP 入口处理，只有中心管理员有权操作，且禁止删除任何管理员账户，包括自己；本步不定义删除 RPC 或实现 HTTP 接口。
