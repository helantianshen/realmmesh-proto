# 游戏服配置拉取 RPC v1

本协议待审查，尚未接入中心或 Mod。协议源文件为 [config.proto](config.proto)。

## 接口与数据

Unary RPC：`/realmmesh.config.v1.ConfigService/GetConfig`。

请求 `GetConfigRequest` 为空。所有游戏服使用中心同一套配置，不接受服务器 ID、版本号或配置键筛选。

| 响应字段 | 类型 | 约定 |
| --- | --- | --- |
| `login_timeout_seconds` | `int32` | 玩家登录时限，单位为秒，范围为 1–2147483647；中心初始化默认 60 |

中心从 `system_configs` 的 `auth.login_timeout_seconds` 读取当前值，仅在初始化时补齐缺失项。运行期配置缺失、非法或读取失败必须报错，不返回默认值。零值与负数不是关闭超时的开关；Mod 收到此类响应应当判定拉取失败。秒数转换为毫秒或纳秒时使用 64 位整数运算。

失败次数与休息时长仍由中心执行，不通过本接口下发。响应不包含密钥、数据库配置、JWT、版本号或通用配置键值映射。

## 服务器认证与错误

沿用 [玩家认证 RPC 的服务器凭据约定](../../auth/v1/README.md)：通过 metadata 携带单个 `x-realmmesh-server-id` 和 `authorization: Bearer <server_secret>`。每次调用校验服务器当前状态与密钥，不因已有 Channel 或上次调用成功而跳过认证。

| gRPC 状态 | 含义 |
| --- | --- |
| `Unauthenticated` | 凭据缺失、无效，或者服务器已停用、删除、密钥已轮换 |
| `Unavailable` | 服务或数据库等依赖暂不可用 |
| `Internal` | 配置缺失、格式错误、超出字段范围或其他内部错误 |
| `DeadlineExceeded` | 超过本次调用期限 |
| `Canceled` | 调用被取消 |

成功响应本身表示配置读取成功，不增加业务状态字段。错误只提供可定位的安全摘要，不输出密钥、完整 metadata、数据库连接串或未经筛选的底层异常。

## 游戏服调用约定

1. 启动时先调用现有带凭据的 `ProbeService.Echo` 检查通信，再调用 `GetConfig`。两个调用均沿用单次 RPC 超时，不无限等待或重试。
2. 健康通信或配置拉取失败，包括收到非法配置，必须中止本次游戏服务器启动并释放客户端资源；不使用本地默认值或旧缓存。内置服只中止本次世界启动，不强制退出整个客户端。
3. 日志记录失败阶段、中心地址、服务器 ID、RPC 状态码及安全原因，便于管理员定位；`Unavailable` 本身不能确定具体网络故障原因。
4. 正常运行后每 30 秒异步拉取，成功时更新内存数值；失败时保留最后一次有效值并记录安全原因，下个周期再尝试，不因此停止游戏服务器。已有请求尚未结束时不叠加拉取，停服后取消请求并丢弃迟到结果。
5. 玩家进入时读取当前值并固定本次登录截止时间。后续刷新不改变已进入玩家的期限；已登录玩家不受影响。

本步只定义协议及调用契约。中心持久化配置、RPC Handler、Mod 启动检查与轮询、未登录门禁均需后续分别实现和验证。
